## 📱 Overview

A simple and elegant **Weather App** built using **Java** and powered by the [OpenWeatherMap API](https://openweathermap.org/).
It delivers accurate forecasts and real-time weather updates for any location.

## ⚙️ Setup

1. Create an account on [OpenWeatherMap](https://openweathermap.org/).
2. Generate your unique API key.
3. Paste it into the file **`LocationCord.java`** as:

```java
public final static String API_KEY = "your_api_key_here";
```
